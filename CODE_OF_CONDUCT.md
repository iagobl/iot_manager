# Code of Conduct

<br>

## Introduction

This repository contains the source code for a **Bachelor's Thesis (TFG - Trabajo de Fin de Grado)** developed as part of the **Degree in Computer Engineering** at the **Universidade da Coruña**.

Although the project is developed individually, the goal is to maintain a **respectful, professional, and inclusive** environment for anyone interacting with the repository—whether reporting bugs, suggesting improvements, or making comments.

## Expected Behavior

Everyone interacting with this repository is expected to:

* Maintain **respectful and professional** conduct in all communications.
* Provide **constructive feedback** when reporting bugs or suggesting improvements.
* Respect different opinions and technical approaches.
* Use clear, appropriate, and respectful language when opening **issues**, comments, or discussions.

## Unacceptable Behavior

The following behaviors will not be tolerated:

* Offensive, discriminatory, or inappropriate language.
* Personal attacks or disrespectful comments.
* Behavior intended to provoke or disrupt the normal operation of the repository.
* Publication of private or sensitive information without authorization.

## Reporting Incidents

If you detect or experience any inappropriate behavior, you can report it by opening an **issue** in the repository or by contacting the project author directly.

Since this project is developed within an **academic context**, response times may vary depending on the author's availability.

## Enforcement

The project author and maintainer reserves the right to **edit, delete, or reject comments, issues, or contributions** that do not comply with this Code of Conduct.
